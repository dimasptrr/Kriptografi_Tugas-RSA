4. Alur Kerja RSA (Studi Kasus Password Manager)

  1. Generate Key: Pengguna memasukkan p dan q. Backend Python menghitung n, φ(n), e, dan d.
  2. Teks → Angka: Password asli diubah menjadi nilai ASCII (modul rsa/converter.py).
  3. Enkripsi RSA: Setiap kode ASCII dienkripsi menggunakan rumus c = m^e mod n (modul rsa/encryption.py).
  4. Penyimpanan Safe: localStorage browser HANYA menyimpan array ciphertext [c1, c2, c3, ...].
  5. Dekripsi RSA: Saat pengguna klik dekripsi, ciphertext dikirim ke Python backend untuk didekripsi menggunakan rumus m = c^d mod n (modul rsa/decryption.py), lalu dikonversi kembali ke teks asli.
